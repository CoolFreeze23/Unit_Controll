## Unit Control

--------------------------------------

Allows controlling units with special 'Unit selection tool' and other tools available through the GUI.

### About this version

This is an unofficial update of Unit Control for Factorio 2.1. It is not affiliated with or endorsed by the original authors.

- Original mod: **Unit Control** by Klonan.
- Factorio 2.0 update ("Unit Control [fixed]") by evandro_6565.
- Factorio 2.1 update: version 2.1.0, see `changelog.txt`.
